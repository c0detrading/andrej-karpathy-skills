Real-time prices (OANDA, optional)

Yahoo's free futures data can lag about 10 minutes. With an OANDA API token, ONYX uses OANDA's real-time prices for every asset OANDA carries (gold, silver, Nasdaq, S&P, Dow, oil, EUR/USD, Bitcoin, Ethereum) and Yahoo for the rest. A free practice (demo) account works: sign up at oanda.com, then Manage API Access → generate a token. OANDA quotes spot/CFD prices, so levels differ slightly from the futures.

Claude news scoring (optional)

Claude re-reads market-relevant headlines and scores them with more nuance than the keyword rules (e.g. "rate cut hopes fade"). Needs an Anthropic API key from console.anthropic.com. At most 200 headlines a day are sent, roughly $0.25/day at most.

Daily briefing

Tuned models

Once a day ONYX tests five models per asset and timeframe on the older 70% of its price history and keeps an alternative only if it also beats the default by at least 0.01% per call on the newest 30%, which it never saw. Edge = average % move in the bias direction per call, on that unseen 30%.
